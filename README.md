# Internet speed test

Консольный скрипт Node.js выполняет 10 HTTP(S)-запросов к указанному адресу **строго последовательно**. Для каждого запроса он ждёт завершения ответа, учитывает реально полученные байты и затем выводит среднее время, суммарный объём и среднюю скорость загрузки.

## Требования

Node.js 18 или новее. Внешние зависимости не нужны.

## Запуск

```bash
node speed-test.js https://example.com/large-image.jpg
```

Или через npm:

```bash
npm start -- https://example.com/large-image.jpg
```

## Тесты

```bash
npm test
```

Тесты используют встроенный модуль `node:test`: они проверяют форматирование единиц, ожидание полного ответа, подсчёт байтов, последовательность запросов, агрегирование результатов и HTTP-перенаправления.

Скрипт поддерживает `http://` и `https://`, следует максимум пяти HTTP-перенаправлениям и прерывает один запрос по тайм-ауту через 30 секунд.

## Единицы измерения

- Время — миллисекунды (`мс`).
- Данные и скорость — двоичные единицы: `КиБ = 1024 Б`, `МиБ = 1024 КиБ`, `ГиБ = 1024 МиБ`.
- Скорость выводится как средняя по всем десяти запросам: суммарный объём данных, делённый на суммарное время выполнения запросов.
